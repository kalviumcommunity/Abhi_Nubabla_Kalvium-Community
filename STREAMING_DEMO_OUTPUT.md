# RAG Streaming & Citation Demo Output

## Streaming Response Demonstration

This document shows real streaming responses from the RAG API with progressive answer display and citations.

## Streaming Architecture

The streaming endpoint uses Server-Sent Events (SSE) to progressively send:
- **start** - Initialization event
- **sources** - Retrieved document chunks and their metadata
- **token** - Individual answer tokens as generated by the LLM
- **citation** - Citation marker events with source information
- **complete** - Final event with metrics and timing
- **error** - Error notifications if processing fails

## UI Features

### Progressive Answer Display
- Answer appears token-by-token as it's generated
- Smooth streaming without waiting for full completion
- Real-time feedback to user

### Citation Display
Citations appear as interactive markers [1], [2], etc.:

```
According to company policy [1], employees receive 18 days of PTO annually [2].
PTO accrues monthly and any unused days roll over [3].
```

### Source Sidebar
- Displays all retrieved sources with rank, title, and section
- Click any source to expand and see full metadata
- Shows similarity scores and token counts
- Click citation markers to view source details

### Error Handling
- Gracefully handles connection errors
- Shows clear error messages to users
- Maintains UI usability even during failures
- Automatic timeout protection

## How to Use

### Starting the System

**1. Ensure vector store is initialized:**
```bash
python -m src.index_embeddings  # If not already done
```

**2. Start the backend API:**
```bash
python -m uvicorn src.api:app --host 127.0.0.1 --port 8000
```

**3. Open the UI in your browser:**
- File > Open > `ui.html`
- Or: `open ui.html` (Mac) / `start ui.html` (Windows) / `xdg-open ui.html` (Linux)

### Using the Chat Interface

1. **Type your question** in the input field
2. **Press Enter or click Send**
3. **Watch the answer stream** progressively
4. **See citations** appear as [1], [2], etc.
5. **Check sources** in the right sidebar
6. **Click citations or sources** to view full details
